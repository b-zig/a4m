# Archi files (generated)

Open Exchange XML files for [Archi](https://www.archimatetool.com/), regenerated by CI from
`models/` after every change on `main`. **Don't edit these files**: edit the YAML under `models/`.

| File | Contents |
|---|---|
| `_landscape.oef.xml` | Every solution architecture and all their views in one model (read-only overview) |
| `<sa>.oef.xml` | One solution architecture, with the other SAs' elements it uses |

**Open in Archi:** download a file (open it on GitHub → *Download raw file*), then in Archi
*File → Import → Open Exchange XML Model…*. Each import creates a new model; to see a newer version,
close the old model and import again.

**Edited in Archi?** *File → Export → Model to Open Exchange File…*, then
`python3 -m a4m import-oef <file> <sa>` to bring the change back into the YAML, one SA at a time.
